# Cross-Corpus Evaluation of Multiple Pose Estimation Methods for Sign Language: Towards Metrics for Accurate Sign Representation

Miguel Yáñez and Ana Aguilera · Universidad de Valparaíso, Chile.

Evaluation of ten HMR methods on PHOENIX-2014-T, CSL-Daily, and LSCh (OF-HMR), including camera alignment and regional reprojection errors.
